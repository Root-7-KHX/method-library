# @local/method-library

DSH 的**本地方法库**：把重复做过的事沉淀成可搜索、可执行的方法卡片。

AI 搜索 → 拿到填好参数的命令或步骤 → 自己执行 → 回报结果入库 → 方法过时可自动修正。

**插件零执行权**：它只检索、填参、发货、记账，绝不 spawn 进程。真正执行的是 AI 用你的终端工具，走你当前会话的权限。

## 安装

```bash
# 从本地目录安装（bundle）
# 在 DSH 里用插件管理器安装本目录，或：
#   plugin_manager action=install_bundle target=D:\AI\插件\method-library
```

装好后顶部标签栏出现「方法库」。

## 目录结构

```
method-library/
  index.js          插件入口：注册工具 / 面板接口 / 系统提示
  lib/engine.js     核心：纯文件存储、BM25 检索、体检、命令拼装、记账
  lib/hub.js        会话层：每会话开关、库目录解析、引擎缓存
  lib/tools.js      5 个 AI 工具
  lib/api.js        面板用的 HTTP 接口（仅本机）
  lib/native-picker.js  原生「选择文件夹」窗口
  client.js         顶部标签入口 + 主区面板
  data/library/     默认方法库（methods.json + scripts/ + logs/ + archive/）
  docs/DETAIL.md    实现细节
  test/             离线自测（见下方「自测」）
```

## 数据

默认 `<插件目录>/data/library`，面板「设置」里可以改到任意文件夹：输入框旁边点 **「选择文件夹…」** 会弹 Windows 原生选择框（和 QQ机器人插件里表情包管理那个一样），选完自动填进输入框，再点「保存并迁移」生效。
所有数据都是纯文件：`methods.json`、`scripts/`、`logs/usage.jsonl`、`archive/`。

「搜不到清单」存在 `data/misses.json`（插件 data 目录，不属于任何库，换库不丢）。

## 会话级（跟 AI记忆 一样的形态）

- 入口：**顶部标签栏**「方法库」（和 对话 / 轨迹 / 上下文 / AI记忆 并排），打开默认是当前对话的库。
- 面板顶部会话切换器：点开是按工作区（文件夹）分组的会话列表，**文件夹默认收起**，点开才看到里面的对话。
- 开关是**滑块**：「本对话」一个，列表里每个对话右边也有一个（不用切过去就能开关）。
- **新对话默认关闭**：要用哪个对话就把它打开（`defaultSessionEnabled: true` 可改回默认开启）。
- 关掉的会话：AI 看不到这 5 个工具，系统提示词也不注入（省 token）；就算硬调工具也会被 `SESSION_DISABLED` 拦下来（面板的只读浏览不受影响，方便你去整理那个库）。
- 每个会话可单独指定库目录；留空跟随全局默认。指定新目录时可勾选「复制当前库一份过去」。
- 会话开关/目录存在 `<插件目录>/data/sessions.json`（不属于任何库，换库不丢）。

## 分类管理

列表上方有一个「按类型分组 / 按标签分组 / 按状态分组 / 按风险分组 / 不分组」的下拉，默认**按类型**（脚本 / 步骤 / 混合）分组：

- 每组一个小标题（▾ + 名字 + 条数），点标题就能收起 / 展开，默认全展开。
- 分组和搜索、状态筛选、只看有问题的叠加生效：先过滤，再分组。
- 按标签分组时用的是方法的**第一个标签**，没打标签的归到「未分类」。
- 选的分类方式记在浏览器 localStorage，下次打开面板还是同一种。

命令行 API（面板用的，仅本机）：`GET /method-library/api/sessions`、`GET /overview?session=<id>`、`POST /enable`、`POST /session-dir`。

## 搜不到的清单（自动捕获）

AI 用 `method_search` 搜空了的时候，插件会把那个查询词记一笔（同一条只累次数，不重复记），面板工具栏点 **「搜不到的（N）」** 就能看到：

- 点 **「转草稿」**：直接建一张同名草稿，补上步骤和参数就能用，不用再手打一遍名字。
- 点 **「不要」**：从清单里丢掉，说明这只是随口一问。
- 只记「搜空」的，有命中就不记；太短的词（一两个字）不记，免得噪声塞满。
- 面板里自己的搜索框不会记（那是你在试关键词），所以清单里只有 AI 真实的缺口。

记录时间戳和次数，按次数排，反复搜不到的排在前面 —— 那就是你的库里最该补的东西。

## 检索

关键词 / 别名 / 标签 + BM25，带**近义词扩展**：查询词会先过一遍同义词表（如「上线前要做的事」能命中「打标签发布」），扩展词按 0.6 权重并入，仍然要求主查询有强命中，不会为了凑数乱召回。

## 配置（cordis.patch.yml）

```yaml
- id: method-library
  config:
    libraryDir: ''        # 留空 = 插件目录下 data/library
    searchLimit: 5        # method_search 默认条数
    draftDays: 90         # 草稿多久没动提示归档
    promptHint: true      # 是否在系统提示注入用法说明
```

## 已知限制

- 不执行命令、不联网（这是设计，不是待办）。
- 检索为关键词/别名/标签 + 近义词扩展 + BM25，仍无向量检索；换个说法但同义词表里没有的说法可能搜不到。
- 自动捕获只记「AI 搜空」的查询，不分析你的意图，也不自动建方法（转草稿要你点一下）。

## 本机环境适配（实测）

- 本机只有 Windows PowerShell 5.1、没有 pwsh 7 → 运行时会自动解析，找不到 pwsh 就用 `powershell.exe`。
- PowerShell 执行策略禁止直接跑 `.ps1` → 默认参数模板带 `-ExecutionPolicy Bypass`。
- PS 5.1 读无 BOM 的 UTF-8 `.ps1` 中文会乱码 → `.ps1` 一律写 UTF-8 BOM。
