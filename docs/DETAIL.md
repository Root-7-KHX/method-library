# 方法库（Method Library）

把「重复做过的事」沉淀成方法卡片：AI 先搜，再取用，执行完回报，方法过时能自己修。

## 它是干什么的

一条**方法卡片** = 名字 + 什么时候用（intent）+ 参数 + 执行体。执行体有三种：

- `script`：指向一个本地脚本（`scripts/` 下的真实文件，可手改、可 git）；
- `playbook`：自然语言步骤（AI 照着做）；
- `hybrid`：先跑脚本，再按步骤收尾。

AI 遇到可能重复的多步任务时，先 `method_search` 搜（中文口语、别名、标签都能搜），命中后 `method_use` 拿到**填好参数的完整命令**或步骤清单。

**插件从不执行任何命令**：命令由 AI 用当前会话的终端工具执行，走当前会话的权限与沙箱；插件只负责检索、填参、发货、记账。

## AI 用的 5 个工具

| 工具 | 作用 |
|---|---|
| `method_search` | 搜方法，只返回卡片清单（id、名字、什么时候用、参数、成功率、体检提示） |
| `method_get` | 看一条方法的全文：参数、脚本路径与正文、步骤、示例、体检问题、上次失败原因 |
| `method_use` | 取用：script 型返回 `command` + `cwd` + `expect`；playbook 型返回步骤；缺必填参数会直接告诉你缺什么 |
| `method_report` | 回报结果（成功/失败 + 备注）；失败时可同轮带 `patch` 直接把方法改好，版本自动 +1 |
| `method_save` | 新建或修改方法（patch 语义），带查重提醒 |

## 面板

入口在**顶部标签栏**：和「对话 / 轨迹 / 上下文 / AI记忆」并排的「方法库」标签，点一下就在对话区打开面板（不占侧边栏）。

- 搜索（本地即时）、状态筛选、只看有问题的、列表 + 编辑区。
- **分类管理**：列表上方有分组下拉，可选「按类型 / 按标签 / 按状态 / 按风险 / 不分组」，默认**按类型**（脚本 / 步骤 / 混合）。每组一个小标题 `▾ 类型名 条数`，点标题收起 / 展开；分组与搜索、状态筛选叠加生效（先过滤再分组）；按标签分组用方法的第一个标签，没标签的归到「未分类」；选的分组方式记在浏览器 localStorage。
- **搜不到的清单**：工具栏上有「搜不到的（N）」按钮，点开是 AI 搜空过的查询词，每条带次数 `×N` 和两个按钮。
  - 「转草稿」：直接把那条查询建成一张草稿卡，补步骤就能用；
  - 「不要」：从清单里丢掉。
- 编辑：方法名、什么时候用、类型、别名、标签、参数定义（JSON）、脚本路径 / 运行时 / 参数模板 / 工作目录 / 预期结果 / 脚本正文、步骤、风险级、状态。
- **试运行只拼命令，不执行**：填好参数点「生成命令」，复制到终端自己跑。
- 历史版本：每次保存会在 `archive/` 留快照，可回滚。
- 导出 / 导入 JSON（换机器、备份、分享）。

## 检索怎么算分

查询先归一化、切词，再过一遍**近义词表**（`expandQuery`）：扩展词以 0.6 的权重并入主查询，但主查询仍要求有强命中，避免为凑数乱召回。所以「上线前要做的事」能命中「打标签发布」，而随便一句闲聊不会把整个库捞出来。

命中排序用 BM25，标题/别名/标签权重高于正文，历史成功率与体检异常参与微调。

## 会话开关与按会话库目录（跟 AI记忆 一样的形态）

- 面板顶部有会话切换器：选中按钮显示 `◉ 会话标题 ▾`，点开是会话列表。
- **会话列表按工作区（文件夹）分组，默认全部收起**，点文件夹那一行才展开；文件夹行右边显示 `开/总` 数量。
- **开关都是滑块**：「本对话」滑块控制当前选中的会话；列表里每个对话右边也有一个小滑块，可直接开关，不用先切过去。
- **新对话默认是关的**：要用哪个对话，就在那个对话上把滑块打开（配置里 `defaultSessionEnabled: true` 可改回默认开启）。
- **关掉的会话**里 AI **看不到这 5 个工具**、系统提示词**一个字都不注入**（省 token）；就算硬调工具也会被 `SESSION_DISABLED` 拦下。面板的只读浏览不受开关影响（你可以切到关着的会话整理那个库）。
- **每个会话可以单独指定库目录**：不同项目各用一个方法库；留空 = 跟随「全局默认库目录」。指定新目录且那里还没有 `methods.json` 时，可以勾「复制当前库一份过去」（复制，不删旧目录），否则从空库开始。
- 会话开关和目录存在插件数据目录的 `sessions.json`（不在库里，换库不会丢）。

## 数据在哪

默认在插件目录下：`<插件目录>/data/library/`

```
methods.json         方法卡片
scripts/             script 型方法引用的脚本文件
logs/usage.jsonl     使用与回报流水
archive/             历史版本与软删除快照
README.txt           一句说明
```

面板「设置」里可以把库目录改到任意文件夹（会把数据复制过去，不删旧目录）。输入框旁边有 **「选择文件夹…」**：点它弹 Windows 原生选择框（和 companion-memory 里表情包管理用的是同一个控件，DPI 感知、中文路径不乱码），选完自动填进输入框，再点「保存并迁移」生效。会话级的库目录也有同一个按钮。所有数据都是纯文件，可直接看、直接改、直接备份。

「搜不到的清单」存在插件数据目录的 `misses.json`（同样不在库里，换库不丢）。只记 AI 搜空且长度够的查询，面板里自己的搜索框不记——那是你在试关键词。

## 体检（只读，不执行）

搜索 / 取详情时顺手检查，不运行任何东西：

- 脚本文件还在不在；
- `path` 类型参数的默认值是否还存在；
- 是否超过 90 天没用了；
- 上次回报失败的原因。

发现问题会在搜索结果和面板里标 ⚠，AI 会先修再用，不用人工巡检。

## 限制

- 插件不执行命令，也不联网；方法能不能跑通取决于本机环境和会话权限。
- 检索是关键词 / 别名 / 标签 + 近义词扩展 + BM25，没有接向量模型（本机没配 embedding 时也不该假装有）；口语说法不一致时，用别名补。
- 自动捕获只记「AI 搜空」的查询，不分析意图、不自动建方法（转草稿要人点一下）。
- 删除是软删除（归档），归档快照在 `archive/`，不会自动清理。

## 本机环境的三个坑（已经处理）

这台机器的真实环境教训，插件里都已规避，别再踩一遍：

1. **只有 Windows PowerShell 5.1，没有 pwsh 7**：命令里的 `pwsh` 跑不起来。插件现在按 PATH → `C:\Program Files\PowerShell\7` → PS 5.1 依次解析，找不到 pwsh 就自动用 `powershell.exe`，并在命令返回里提示。
2. **PowerShell 执行策略禁止直接跑 `.ps1`**：默认参数模板已带 `-ExecutionPolicy Bypass`。
3. **PS 5.1 读无 BOM 的 UTF-8 `.ps1` 会把中文读成乱码**（字符串引号都可能被撑坏）：插件内 `.ps1` 一律带 UTF-8 BOM；`.sh/.mjs/.py` 不加，避免 shebang 失效。
